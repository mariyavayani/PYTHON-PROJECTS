# Python Projects

A collection of Python projects built while strengthening my programming fundamentals — 
covering file handling, functions, OOP, and basic automation.

## Projects

### 1. Hangman Game
A command-line Hangman game with ASCII art that updates as guesses are made, 
randomized word selection from a 100-word bank, and input validation 
(handles duplicate guesses, invalid characters, and multi-letter input).
**Concepts:** file/module imports, string manipulation, sets, randomization, game loops



## File Structure
- `hangman.py` — main game logic
- `Words.py` — word bank

### 2. Student Management System (Functional)
A functions-based system to add, update, and manage student records.
**Concepts:** functions, data structures, control flow

### 3. Student Management System (OOP)
A refactor of the project above using Object-Oriented Programming principles — 
classes, encapsulation, and cleaner structure.
**Concepts:** OOP, classes, encapsulation

### 4. Chatbot
A rule-based command-line chatbot that matches user input against predefined 
patterns and returns contextual replies, with handling for empty input and a 
graceful exit on farewell messages.
**Concepts:** conditionals, string matching/normalization, control flow, loops

### 5. Stock Portfolio Tracker
A command-line tool to build a mock stock portfolio and calculate its total value 
using a predefined set of stock prices. Supports input validation, a formatted 
summary view, and exporting the summary to a `.txt` file.
**Concepts:** dictionaries, functions, file I/O, input validation, formatted output
